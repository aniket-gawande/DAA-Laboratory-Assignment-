# Design and Analysis of Algorithms (DAA) Laboratory Assignments

This repository contains C++ implementations and datasets for Design and Analysis of Algorithms (DAA) laboratory practical assignments.

## Contents

- **Assignment 1:** Merge Sort implementation and performance analysis on Retail Transaction Dataset.
- **Assignment 2:** Quick Sort implementation on Movie dataset.
- **Assignment 3:** Fractional Knapsack Problem using Greedy strategy.
- **Assignment 4:** Single Source Shortest Path using Dijkstra's Algorithm.
- **Assignment 5:** Shortest Path in Multistage Graph using Dynamic Programming.
